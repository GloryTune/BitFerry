# BitFerry 🚢

**跨平台局域网文件互传 + 即时聊天工具**，基于 PyQt6 开发，支持 macOS 与 Windows。

只需连接同一 Wi-Fi 或插入同一根网线，即可在设备之间快速传输文件、截图、文字，无需互联网、无需账号。

## 功能特性

- **自动发现设备** — 同一局域网内的设备自动出现在列表中，在线/离线状态实时显示
- **文字聊天** — 支持换行（Shift+Enter），消息按会话和日期分组显示
- **文件传输** — 单个文件、多个文件、整个文件夹一次性打包发送
- **截图发送** — 快捷键唤出区域截图工具，截图直接进入输入框发送（macOS 原生 / Windows 系统截图）
- **图片粘贴/拖入** — 剪贴板图片、图片文件直接拖入输入框，自动嵌入显示
- **聊天记录持久化** — 历史消息本地保存，可随时翻阅与特定设备的全部聊天记录
- **未读消息提示** — 角标、系统通知、Dock 闪烁三重提醒
- **自定义接收目录** — 收到的文件按发送方机器名自动归档，存放位置可自由更改
- **设备管理** — 右键可删除长期离线的历史设备
- **手动刷新** — 点击「↻ 刷新」按钮立即重新扫描局域网设备
- **图标内嵌** — 应用图标直接编译进程序，跨机器运行无需附带任何资源文件
- **多套主题** — 内置 5 套精心设计的主题（深夜 / 素纸 / 晚霞 / 霜白 / 玄金），点击色板实时预览，取消可回滚
- **图片右键菜单** — 聊天中的图片支持右键「复制图片 / 另存为 / 打开 / 在文件夹中显示」；单击聚焦后 Ctrl+C 直接复制到剪贴板
- **文件右键菜单** — 文件卡片支持右键「打开 / 在文件夹中显示 / 另存为」；双击打开文件
- **失败重试与发送队列** — 文字、图片和文件发送失败后可在气泡上重试；侧栏「发送队列」可查看等待、发送中、失败及未确认任务，并逐项重试或撤销
- **会话独立草稿** — 自动保存各会话的文字、内嵌图片、附件和光标位置，重启后继续编辑；失效附件会标记
- **待接收文件恢复** — 手动确认模式的待接收清单持久化保存，重启后可以继续接收或拒绝；处理失败的项目会保留
- **历史搜索与分页** — SQLite 增量保存，后台按文字、文件名或日期搜索，数据库每次只读取一页，最多显示 50 条消息
- **后台扫描文件夹** — 添加文件夹时在后台扫描，附件显示文件数量、总大小和扫描状态，发送时使用本次扫描的文件清单
- **截图文字字号** — 截图标注工具和图片编辑器均支持 8–96 pt 字号；选中文字后可调整大小，设置会记住

```bash
git clone https://github.com/GloryTune/BitFerry.git
cd BitFerry
```

### 2. 安装依赖

```bash
pip install PyQt6 certifi qrcode
```

```bash
python bitferry.py
```

## 打包为独立应用（无需 Python 环境）

### macOS — 打包为 `.app`

**前提：** 安装 PyInstaller

```bash
pip install pyinstaller
```

**执行打包：**

```bash
pyinstaller bitferry.spec --clean --noconfirm
```

打包完成后，可运行的应用位于：

```
dist/BitFerry.app
```

将 `BitFerry.app` 拖入 `/Applications` 即可像普通 Mac 应用一样使用，双击启动，无需安装 Python。

> **体积说明：** 打包后约 130 MB（压缩包），包含完整 Qt 框架，这是 PyQt6 应用的正常体积。

---

### Windows — 打包为 `.exe`

仓库已提供 Windows 专用打包配置 `bitferry_win.spec`（单文件、无控制台窗口）。在 Windows 机器上执行：

```bash
python -m pip install PyQt6 certifi qrcode mss pyinstaller
python -m PyInstaller bitferry_win.spec --clean --noconfirm
```

打包完成后，单个可执行文件位于：

```
dist\BitFerry-windows-x64.exe
```

直接把这个 `BitFerry-windows-x64.exe` 发给别人即可双击运行，无需附带任何其它文件。

> 这正是 [Releases 页面](https://github.com/GloryTune/BitFerry/releases/latest) 中预编译包的构建方式——一般用户直接下载即可，无需自行打包。

## 使用教程

### 启动与设备发现

1. 在两台（或更多）设备上同时启动 BitFerry。
2. 确保设备连接在**同一 Wi-Fi** 或接入**同一台交换机/路由器**的网线。
3. 左侧设备栏会在几秒内自动显示发现的设备，**绿点** 表示在线，**灰点** 表示曾经连接过但当前离线。
4. 若未发现设备，点击「**↻ 刷新**」按钮手动触发一次广播扫描。

---

### 发送文字消息

1. 在左侧点击目标设备。
2. 在底部输入框中输入文字。
3. 按 **Enter** 发送，**Shift+Enter** 换行。

---

### 发送文件

**方式一：拖放**
- 直接将文件/文件夹从 Finder（或资源管理器）拖入输入框。

**方式二：按钮**
- 点击工具栏「**📎 文件**」选择单个或多个文件。
- 点击「**📁 文件夹**」选择整个文件夹（内部文件结构会完整保留）。

**方式三：粘贴路径**
- 在 Finder 中复制文件（⌘C），在输入框中粘贴（⌘V），自动识别并添加为附件。

文件以「芯片」形式显示在输入框下方，点击 **✕** 可移除，准备好后点击**发送**。

收到的文件保存在对方设备的接收目录，按**发送方机器名**自动归档到子文件夹：

```
~/BitFerry_Received/
  └── MacBook-Pro/
        ├── 项目方案.pdf
        └── 设计稿.fig
```

---

### 发送截图

**方法一：工具栏按钮**
- 点击「**✂ 截图**」按钮，窗口自动隐藏，拖选区域后松手，截图进入输入框。

**方法二：全局快捷键**
- 默认快捷键（macOS / Windows 统一）：`Alt+Shift+A`（macOS 上 Alt 即 Option 键 `⌥⇧A`）
- 可点击右上角「**⌨ 快捷键**」自定义快捷键。

截图以缩略图形式内嵌在输入框中，支持与文字混排后一起发送。

在应用内截图工具中选择「文字」，使用工具栏的「字号」设置文字大小。也可双击输入框中的图片打开编辑器，在其中添加文字或调整选中文字的字号。双击已有文字标注可修改内容，保留原位置、颜色和字号。新生成的本机截图会保留编辑信息，保存、关闭或重启后仍可继续编辑；发送给对方的仍是普通 PNG。旧截图、外部图片中已经合并的文字无法还原成标注；裁剪和旋转也会合并现有标注。

---

### 发送剪贴板图片

- 截图后（系统截图工具或 QQ 截图等），在输入框内按 **⌘V / Ctrl+V** 粘贴，图片自动进入输入框。
- 或点击工具栏「**📋 粘贴**」按钮。

---

### 查看聊天记录

- 点击聊天窗口右上角「**🕘 聊天记录**」，查看与该设备的完整历史消息（含日期分隔）。
- 聊天记录本地持久化保存，重启应用后仍可查阅。
- 在搜索框输入关键词、文件名或日期筛选；使用「上一页 / 下一页」翻阅，每页最多 50 条。点击搜索结果下的「定位此消息 · 查看上下文」，跳到原始记录所在页并标出目标消息。失败消息可直接点击「重试」。

> **注意：** 主聊天窗口显示本次启动后的消息，初始加载最近 100 条，向上滚动或点击「加载更早消息」继续查看，最多同时保留 500 个消息组件；「回到最新」返回最新消息。浏览旧消息时，新消息不会强制跳走。跨重启记录通过「聊天记录」查看。

### 发送队列与重试

- 点击左侧「**发送队列**」查看未完成任务。新任务绑定接收设备身份，原设备换 IP 后仍可补发；IP 被其他设备复用时不会把旧任务发给新设备。旧版本未保存身份的任务需先确认接收设备，成功的任务从队列移除。
- 撤销结果必须成功保存才会显示已撤销；保存失败时保留任务并提示重试。
- 失败时，原文字、图片路径和文件清单会保留，点击气泡或队列中的「**重试**」只重试选中的任务。重试前按文件大小和修改时间检查源文件：变化或缺少原版本信息时需确认发送当前版本；已删除、移动或无法读取时阻止发送。自动补发遇到变化也会暂停对应任务。
- 「**未确认接收**」表示没有收到回执，或上次退出时任务仍在发送。请先核实对方是否收到，手动重试前会提示可能重复发送。
- 点击「**撤销**」移除等待任务，或中断尚未完成的发送。撤销不能删除已经交付给对方的内容。
- 待确认接收的文件重启后仍会显示在对应设备的接收提示中。移动失败时会保留待处理项目和错误日志。

---

### 自定义接收目录

- 左侧「**接收目录**」卡片下点击「**更改位置**」，选择新路径。
- 点击「**打开**」可直接在 Finder/资源管理器中查看收到的文件。
- 更改只影响新收到的文件，不移动已存在的文件。

---

### 切换主题

点击右上角「**⚙ 设置**」，在「外观主题」区域点击任意色板，主窗口**实时预览**新主题效果；点击「保存」确认，点击「取消」自动回滚到原主题。

内置 5 套主题：

| 主题 | 风格 |
|------|------|
| 深夜 | 深海蓝炭灰，电光蓝强调，中等圆角 |
| 素纸 | 暖奶油白（浅色），墨玉绿强调，方正线条 |
| 晚霞 | 深紫丝绒，珊瑚橙强调，最大圆角 |
| 霜白 | 冷调浅灰白（浅色），宝石蓝强调 |
| 玄金 | 近纯黑，暖金强调，金色侧边线，极锐利边角 |

---

### 查看 / 保存聊天中的图片与文件

- **图片**：单击聚焦，聚焦后按 **Ctrl+C / ⌘C** 将图片复制到剪贴板；双击用系统默认应用打开；**右键**可选择「复制图片」「另存为…」「在文件夹中显示」。
- **文件**：单击聚焦；双击打开文件；**右键**可选择「打开文件」「在文件夹中显示」「另存为…」。

---

### 管理设备列表

- **删除设备：** 右键点击左侧设备列表中的离线设备，选择「**删除设备**」，该设备及其聊天记录将被清除。在线设备无法删除。
- **手动刷新：** 点击设备列表右上方「**↻ 刷新**」按钮，立即发送广播重新扫描设备。

| 端口 | 协议 | 用途 |
|------|------|------|

### 接收与记录可靠性

- 手机同时上传同名文件会分别保存，避免并发覆盖。手动确认接收设置同样适用于手机上传；网页输入法选词时按 Enter 不会误发送。
- 待确认文件的接收和拒绝在后台处理，窗口显示处理状态，重复点击不会重复处理。退出或安装更新会等待处理完成。文件夹仍采用复制后清理的方式，需要足够的目标磁盘空间。
- 聊天记录使用 SQLite 事务增量保存。首次启动自动迁移旧 JSON（损坏时尝试读取旧备份），原文件保留；迁移失败可重试，不重复导入。后续启动不再全量读取 JSON。
- 删除离线设备时，如有待发任务，可以选择保留或一并撤销；撤销保存失败时保留设备和任务。
- 草稿在停止输入约半秒后保存，正常退出时再次保存。未完成的文件夹扫描重启后会标记为需重新添加。

### 1.2 使用体验与诊断

- 深夜、晚霞、玄金设置页的文字随主题切换刷新，设置内容区和提示文字均适配深色背景。
- 手机网页使用跨重启唯一消息编号；重连后检查原下载链接。源文件仍存在且登记未过期时可继续下载，失效链接提示重新发送。
- 存在网络传输、附件检查或后台接收处理时，退出会询问是否等待完成；等待期间暂停新任务，侧栏可以取消等待。暂停中的发送须先恢复或撤销。安装更新也会等待当前任务完成。
- 大批量附件在后台检查，过程中切换会话或修改输入不会直接发送新草稿；草稿按顺序在后台保存，正常退出会等待保存完成。
- 发送队列支持按接收设备、状态筛选，选中多行后批量重试或撤销。设备列显示创建任务时绑定的接收方。
- 「设置 → 日志与存储」可统计截图与暂存文件占用。仅清理超过 24 小时且未被历史、草稿、任务、待接收清单或下载登记引用的缓存；不删除正式接收目录中的文件。

### 操作日志

- 默认位置：`接收目录/log/YYYY-MM-DD.log`，例如 `log/2026-09-11.log`。更改接收目录后，新日志写入新目录。
- 按本机日期每天一份，保留今天及之前 6 天，共 7 个自然日。启动、写入新日期日志及跨日检查时清理超期的日期日志，不删除目录内其他文件。
- 记录版本和平台、启动退出、重复启动唤起、任务创建/重试/撤销/结果、接收处理、设备和设置变更、缓存清理、持久化错误和未捕获异常等诊断信息。包含任务 ID、设备身份、文件相关信息及失败原因；不记录聊天正文，连接 URL 中的口令参数会脱敏。
- 「日志与存储」显示当前运行的最近日志，可筛选错误与警告，并导出最近 7 天日志 ZIP。日志保存失败也会出现在最近错误中。

### 2.0 发送确认与接收修复

- 设备发现广播声明本机会发送接收回执。对未声明的旧版本设备（1.2 及更早），数据发完后对方正常断开即视为已接收；超时或连接被重置仍标记为未确认。
- 侧栏「待发」只统计仍会自动发送的任务，已送达、已撤销和未确认的任务不计入。
- 修复 Windows 上并发接收同名文件时，路径解析偶发保留 `\\?\` 前缀导致误判越界拒收。

### 2.01 界面与使用体验

- 发送队列、日志与存储归入设置，主界面突出设备和聊天；接收文件夹使用紧凑快捷按钮。
- “回到最新”只在离开最新消息时显示，正常接收状态不再常驻提示。
- 设置可修改本机名称、设置截图时是否隐藏窗口，与主界面入口同步。
- 设置旁新增使用帮助，覆盖首次互传、截图编辑、手机互传、离线队列与历史搜索。
- 优化输入区、工具栏和离线设备文字对比度。
